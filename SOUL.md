## Media Memory
- Before generating or referencing any visual asset, run: node skills/media-memory/search.js "{description}" 3
- If score > 0.85 on a result, reuse or reference the existing asset instead of generating new
- When user asks about past media ("the image we made", "that video", "the photo of X"), always query media memory first
- New assets generated by any workflow should be registered via the webhook at localhost:5678/webhook/media-memory-generated
